Research Plan: Evaluating Chest X-ray Foundation Models on MIMIC-CXR-JPG

1. Background 2. Aims 3. Dataset 4. Models 5. Papers 6. Experiments 7. Analysis

Proposed study focus: Evaluate whether chest X-ray-specific foundation models and general medical vision-language foundation models provide useful representations for disease classification, zero-shot prediction, and image-report alignment on MIMIC-CXR-JPG.

Core idea: Instead of training a large model from scratch, use pretrained foundation models to extract image/text embeddings from MIMIC-CXR-JPG, then evaluate them under the same downstream tasks and metrics.

1. Background and Motivation

The previous research direction based on subject-level merging produced too few usable samples. MIMIC-CXR-JPG provides a much larger and more suitable dataset for a chest X-ray AI study because it includes chest radiographs and associated radiology reports.

The main research question is:

Do CXR-specific foundation models outperform general medical vision-language foundation models on MIMIC-CXR, and under what conditions?

This question is important because MIMIC-CXR-JPG is a chest X-ray dataset. Therefore, one might expect a CXR-specific model to perform better. However, newer general medical vision-language models such as MedSigLIP may be stronger for text-based tasks such as zero-shot classification and image-report retrieval.

2. Main Research Aims

Aim Description Expected Output
Aim 1 Compare pretrained foundation model embeddings for MIMIC-CXR disease classification. AUROC/AUPRC/F1 for 14 CheXpert-style labels.
Aim 2 Evaluate label efficiency using 1%, 5%, 10%, and 100% of training labels. Performance curves showing which model works best with limited labels.
Aim 3 Evaluate zero-shot classification for models with text encoders. Zero-shot performance using disease prompts such as “pneumothorax present”.
Aim 4 Evaluate image-report alignment using MIMIC-CXR reports. Image-to-report and report-to-image retrieval metrics.

3. Primary Dataset

3.1 MIMIC-CXR-JPG

Official link: MIMIC-CXR-JPG v2.1.0 - PhysioNet

MIMIC-CXR-JPG is the recommended starting point for this project because it provides JPG images and structured labels derived from radiology reports. This makes it easier to run image classification experiments without directly processing DICOM files.

3.2 Labels

Use the structured labels provided with MIMIC-CXR-JPG. The main labels are based on common chest X-ray findings, including:

  • Atelectasis
  • Cardiomegaly
  • Consolidation
  • Edema
  • Enlarged cardiomediastinum
  • Fracture
  • Lung lesion
  • Lung opacity
  • No finding
  • Pleural effusion
  • Pleural other
  • Pneumonia
  • Pneumothorax
  • Support devices
Important: MIMIC-CXR-JPG is a credentialed dataset. Do not upload images or reports to third-party online APIs unless explicitly allowed by the PhysioNet data use agreement.

6. Proposed Experimental Design

Experiment 1: Supervised Disease Classification

Goal: Compare whether embeddings from each foundation model can predict MIMIC-CXR disease labels.

  1. Use MIMIC-CXR-JPG images and structured labels.
  2. Use the official train/validation/test split if available.
  3. For each model, extract one embedding vector per image.
  4. Train the same lightweight classifier on top of each embedding set.
  5. Use logistic regression as the main classifier; optionally add LightGBM or a small MLP as sensitivity analysis.
  6. Evaluate performance on the test set.

Main metrics: AUROC, AUPRC, macro-F1, per-label F1.

Experiment 2: Label-Efficiency Analysis

Goal: Test which foundation model works best when labeled data are limited.

  1. Use 1%, 5%, 10%, and 100% of the training set labels.
  2. Keep the validation and test sets fixed.
  3. Train the same classifier under each label percentage.
  4. Compare performance curves across models.

Core question: Does MedSigLIP, CXR Foundation, BioViL, EVA-X, or CheXFound provide the best representation when labels are scarce?

Experiment 3: Zero-Shot Classification

Goal: Test models with text encoders without training a disease classifier.

Candidate models: MedSigLIP, BioViL/BioViL-T.

For each disease, create simple positive and negative prompts:

Disease Positive Prompt Negative Prompt
Pneumothorax “pneumothorax present” “no pneumothorax”
Pleural effusion “pleural effusion present” “no pleural effusion”
Cardiomegaly “cardiomegaly present” “normal heart size”
Pneumonia “pneumonia present” “no pneumonia”

Compute image-text similarity and classify the image based on which prompt is closer.

Experiment 4: Image-Report Retrieval

Goal: Use MIMIC-CXR reports to test image-text alignment.

  1. Use the image and its paired report impression/findings section.
  2. Extract image embeddings and text embeddings.
  3. Perform image-to-report retrieval and report-to-image retrieval.
  4. Evaluate whether the correct paired report/image appears in the top-k results.

Main metrics: Recall@1, Recall@5, Recall@10, mean reciprocal rank.

7. Analysis Plan

Analysis Purpose
Overall performance comparison Identify the best-performing model on average.
Disease-specific analysis Determine which models are better for specific findings such as pneumothorax, pleural effusion, pneumonia, or cardiomegaly.
Common vs rare labels Test whether some models perform better for long-tail findings.
Zero-shot vs supervised comparison Find when prompt-based prediction is useful and when supervised classifiers are necessary.
CXR-specific vs general medical model comparison Answer whether CXR-specific specialization still matters compared with newer general medical VLMs.
